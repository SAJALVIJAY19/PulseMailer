Built for real marketing workflows

A/B Variants

Generate up to 5 unique email variants in a single request. Test different angles and pick the winner.

Automated Scheduling

Set any campaign to repeat weekly. APScheduler runs it automatically — no manual work.

Campaign Memory

Every campaign saved to PostgreSQL. Full history with search, filter and re-use.

Redis Caching

Identical prompts served from cache instantly. Track cache hit rate on the analytics dashboard.
